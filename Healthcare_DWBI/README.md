### ***Healthcare Appointment Analytics - Data Warehousing \& Business Intelligence***

**1.Overview**

This project demonstrates an end-to-end Data Warehousing and Business Intelligence solution for analysing healthcare appointment attendance and patient no-show behaviour.



**2.Technologies Used**

* Microsoft SQL Server
* SQL
* ETL
* SSAS
* OLAP
* Power BI



**3.Key Features**

* Integrated CSV, Excel and JSON data sources
* Designed Healthcare Data Warehouse
* Built SQL-based ETL pipelines
* Developed Appointment Management Data Mart
* Created SSAS Multidimensional Cube
* Developed Interactive Power BI Dashboards



**4.Key Results**

* 110,526 Healthcare Appointments Analysed
* 22,319 No-Show Appointments Identified
* 20.19% No-Show Rate
* 98.77% Location Enrichment Match
* 100% Healthcare Facility Match



**5.Project Structure**

* Raw Data
* Database Scripts
* ETL Processes
* SSAS Cube
* Power BI Reports
* Screenshots
* Final Report
