🏥 Healthcare Appointment Analytics – Data Warehousing & Business Intelligence
A comprehensive Data Warehousing and Business Intelligence (DWBI) solution developed to analyze healthcare appointment attendance and identify patient no-show patterns using SQL Server, SSAS, and Power BI.

📌 Project Overview
This project was developed as part of the BSc (Hons) in Information Technology – Data Science degree program at Sri Lanka Institute of Information Technology (SLIIT).

The solution integrates healthcare appointment data from multiple sources, performs ETL processing, stores data in a dimensional data warehouse, enables OLAP analysis through SSAS, and delivers business insights through interactive Power BI dashboards.

🎯 Objectives
Analyze healthcare appointment attendance patterns.
Identify factors associated with patient no-shows.
Design and implement a dimensional data warehouse.
Develop ETL processes for data integration and validation.
Build OLAP cubes for multidimensional analysis.
Create interactive business intelligence dashboards for decision support.
